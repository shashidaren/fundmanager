# FundPilot MY — Self-Improving Layman Fund Manager

Beginner-friendly portfolio planner and self-improving recommendation dashboard combining **Versa Malaysia Portfolios (MYR)** and **Broad US Non-Individual Stock ETFs (USD)**, with an instant **All Funds / Shariah-Only (`-i` / Halal)** filter toggle, automated market-driven calibration, and continuous reference syncing to **[`handoff.md`](./handoff.md)**.

## Quick Start

```bash
# Install dependencies
npm install

# Run unified dashboard + API server (http://0.0.0.0:3000)
npm run dev

# Run market-driven self-improvement calibration & update handoff.md
npm run calibrate

# Run automated test suite
npm test
```
